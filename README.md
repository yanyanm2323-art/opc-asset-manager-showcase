# OPC Asset Manager · OPC 资产管理

OPC Asset Manager is a local-first macOS app for keeping track of fixed assets, consumables, and related credentials. It brings records, attachments, and audit history into one place.

![OPC Asset Manager on macOS, showing the fixed-asset inventory with search and filters](https://yanyanm2323.com/projects/opc-showcase.png)

*Fixed-asset inventory with sample data.*

## A typical workflow

1. Search by asset name, inventory number, or serial number. Use filters such as category, department, or custodian to narrow the list.
2. Review the asset's status and location. Add a record when new equipment arrives.
3. Export the inventory to Excel when you need to work with it outside the app.

## Why local-first

Asset records can include purchase details, attachments, and information about who uses equipment. Keeping the core records in encrypted files on the device lets users manage that inventory without relying on a server. The app uses macOS Keychain for sensitive credentials. Users explicitly initiate imports and exports, which gives them control over when data moves into or out of the app.
